# Prompt library

These are patterns that worked on the Adrian reels, rewritten so they fit any founder. Replace each `<…>` before use. Every prompt follows the same order: **duration and aspect → references → timed shots → camera, action, expression → audio → continuity → exclusions**.

The rules that apply to every prompt:
- Each image gets one job: identity, location, prop or composition. Add "do not reproduce the sheet layout."
- Prompts never ask for music, SFX or text. Those go on in the edit.
- Mouths stay closed unless a line is lip-synced to @Audio.

---

## 1 · Lip-sync on one line only
*Use when:* the VO plays over B-roll and the founder says one key line to the lens. *From:* Reel 2, The Price Tag.
```
<N>-second video, native 9:16, <shots> shots with hard cuts at about <t1> and <t2> s.
@Image 1: <founder> identity and clothing. Preserve face, hair, build, outfit. Do not reproduce the sheet layout.
@Image 2: <location>. Preserve layout, furniture and lighting.
@Audio 1: only the recording of "<line>". Use it as the speech and lip-sync reference ONLY for the final shot.
SHOT 1 (0–<t1>): <medium shot, face visible, doing the everyday action>. Mouth closed. Silent B-roll.
SHOT 2 (<t1>–<t2>): hard cut wider, revealing <the new information: empty chairs, the mess, the crowd>. Mouth closed.
SHOT 3 (<t2>–<N>): medium close-up from <a propped phone / across the table>. <Founder> stops <action>, raises their eyes to the lens and says "<line>", synced to @Audio 1. Hold eye contact briefly after the line, then end.
AUDIO: shots 1–2 room ambience only; shot 3 the @Audio 1 line only. No narration, no music.
CONTINUITY: same person, outfit, seat, props and lighting across shots.
No captions, text, extra people, exaggerated sadness, slow motion or cinematic blur.
```
*Note:* the cut times are provisional. Stretch the last shot to fit the real delivery.

## 2 · Narrated scene where only some characters speak
*Use when:* the VO runs over the whole clip and one or two lines are spoken by people on screen. *From:* Reel 5, clip 3.
```
9:16, <N> s, photorealistic, <era look>. Multi-shot with hard cuts.
@Image 1 location · @Image 2 <character A> · @Image 3 <character B> · @Image 4 <key prop>.
Use @Audio 1 as the timing and lip-sync reference. Only these lines are spoken on screen: <A> says "<line>" from <t>s to <t>s; <B> says "<line>" from <t>s to <t>s. Everything else in @Audio 1 is narration: nobody moves their lips to it, and all mouths stay closed.
<timed shots, each with one clear action>
Plant <payoff prop> in frame from the first shot so the later line pays it off.
Keep faces, wardrobe, props and lighting consistent throughout.
```
*Backup if the sync drifts:* cut each spoken line into a short audio file and generate it as its own shot.

## 3 · Open close, then reveal wider
*Use when:* the hook pairs a proud fact with a hidden cost. Starting close makes the wider shot add information. *From:* Reel 2 revision.
```
Shot 1: medium, the face clearly visible, <founder> absorbed in <work>. The on-screen number is added in the edit.
Shot 2: hard cut wider from the same side, revealing <what's missing or wrong>. <Founder> keeps going and does not react.
Shot 3: close. <Founder> stops and looks toward the lens.
```

## 4 · The same room, before and after
*Use when:* the solution answers a problem shown earlier in the story. *From:* Reel 1 ending, Reel 6 payoff.
```
<N> s, 9:16. @Image 1 = <the room, before> · @Image 2 = <the room, after> · @Image 3 = <founder>.
0–<t>: <the before state, framed exactly like the earlier problem shot>.
<t>–<N>: the same framing and the same person. ONE clear change happens by itself: <light fades on / door unlocks / shelf is full>.
One on/off event per shot. Keep the camera position identical so the change reads.
```

## 5 · Time passing in one locked frame
*Use when:* you need to show hours going by without a time-lapse. *From:* Reel 5, the coffee cups.
```
Three hard cuts of the SAME locked-off wide shot. Each cut changes one thing: <cups 2 → many>, <people laughing>, <light warmer>. No objects multiplying within a shot.
```

## 6 · Two time periods in one clip
*From:* Reel 5, clip 4.
```
Two time periods: <past> has 35mm grain and faded colour; <present> is clean and sharp with no grain. State which one each shot belongs to. Mirror one gesture across the cut (the same disgusted look, the same hand movement).
```

## 7 · Hands-only insert for people who don't appear on screen
*From:* Reel 6 (the girlfriend and parents).
```
Close insert, no face visible. A <woman's / older man's> hand <sets down the takeaway / closes the gate>. Framed from the chest down or at table height.
```

## 8 · Quiet, internal emotion
*From:* the Reel 2 Japan hotel scenes.
```
<Founder> <lies awake / sits on the bed edge>. Almost no movement: natural blinks, one small adjustment, a soft exhale. The emotion stays internal and understated.
No crying, no hands on the forehead, no head in hands, no chin on palm, no dramatic sigh.
```

## 9 · Keyframe image (for a look check before video)
```
Single 9:16 photorealistic still. @Image 1 identity, @Image 2 location. <composition>. <light reference>.
<Text overlay, for concept only. The final video must be text-free.>
```
