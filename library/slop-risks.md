# Slop risks and fixes

Before writing a prompt, check the shot against this list. Add any risks that apply to the edit plan's **Slop risks** line.

| Risk | What goes wrong | Fix |
|---|---|---|
| **Darkness** | Pitch black turns into noise and mush | Use blue moonlight through a window, never true black. Show only eyes or a silhouette |
| **Fast motion** (running, diving, fights) | Limbs warp and bodies melt | Keep it under 1.5 s, in one wide shot, or cut it. Prefer slow, step-by-step moves |
| **Hands doing fine work** (sewing, typing close-up, counting money) | Extra fingers, objects passing through hands | Use real footage for close-ups. Use one simple hand action, such as a hand rub instead of rolling up sleeves |
| **Text and logos** | Gibberish signs, fake brands | Add "no text, logos or signage." Keep walls out of focus. Add text in the edit |
| **Many objects** (stacks of plates, crowds) | Objects multiply or vanish | Reduce the count (2 plates, not a stack). Use locked-frame hard cuts for "more" |
| **Things turning on by themselves** | Flicker, several changes at once | One clear on/off event per shot |
| **Lighting changes** | Odd, unmotivated light | Give the change a reason (the room starts dim, then someone brightens it). Make one slow change |
| **Unmotivated actions** | The action reads as wrong (the mum turns the light off while others are using it) | Ask "what does this action say?" before generating |
| **Identity drift across cuts** | Face, age or outfit changes | One identity reference, reused. State the outfit in words. Keep shots within one generation where possible |
| **Character sheet artefacts** | The generation copies the sheet layout or a headless view | Add "do not reproduce the sheet layout." Fix headless or blank views before using the sheet |
| **Lip movement during narration** | Characters mouth the VO | "Everything else is narration: all mouths stay closed" |
| **Over-acting** | Crying, head in hands, big sighs | Ask for understated behaviour and list the banned gestures (see prompt library #8) |
| **Wrong aspect ratio** | 16:9 cropped into 9:16 | Ask for native 9:16 composition in every prompt and every reference sheet |
| **Look-alikes and IP** | Celebrity or film imitation (the Terminator, for example) | Keep the joke in the words. Never show the look-alike |
| **Too "cinematic"** | Polished AI ad look on a casual story | Say "phone footage, deep focus, ordinary light, slightly imperfect framing" |
